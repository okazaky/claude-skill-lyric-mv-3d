# 3D歌詞MV の作り方

エンジンの実物: 環境変数 `LYRIC_MV_ENGINE` が指すフォルダ（このリポジトリの `engine/`。エンジン・前作の場面・`implementation-notes.md` に依頼者の指摘と直し方が入っている）。
本スキルはこのフォルダをテンプレートとして複製し、曲ごとに場面だけを作り直す。縦長MVの完成例の場面コードは `examples/yoru-code/`。

## 依頼者の好み（守ること）
- 欲しいのは **3Dの物体・カメラの動き・奥行き・1行ごとの大胆な絵**。平面の計器表示＋大きな文字は「字幕つけただけ」と却下された。
- **拍ごとに揺らさない**（エンジンの kick は0にしてある）。動きはカメラの連続した移動と、歌詞の言葉の頭での出来事だけ。
- 同時に動く要素は2〜3個まで。拍に合わせて5つ動かした場面は「うざい」と言われた。
- 色は黒・骨色・オレンジの3色。オレンジは画面の1〜2割まで。
- 縦長ショートを頼まれたら `--vertical`（1080×1920）。参考の前作は横長だが、依頼の向きを優先する。
- 場面の頭が真っ暗だと流れが切れる。前の場面がにぎやかなときほど、最初のコマから主役の物体を見せる。
- **英語の言葉をカタカナで歌っているところは、画面では英語で出す**（例: クロ→Claude、コード→code）。歌詞の文字面どおりにカタカナで出すと「いちいち指摘させるな」と言われた（2026-10-07）。台割を作る段階で、カタカナの語が英単語や固有名詞の当て字かどうかを確かめ、表示用の文字を決めておく。文字数が変わるので、1文字ずつ節に合わせて出す場面は、語の単位で出すか、文字を節に割り振り直す。
- **音の変わり目（ブレイク明け・楽器が一斉に入る・急に抜ける）には、映像の切り替わりを合わせる**。歌詞の行の頭だけで場面を切ると、行の途中の変わり目を取り逃がす（2026-10-07、0:15 と 0:28 で指摘）。拍ごとに低音・中音・高音の音量を測り、前後4拍の差が大きい拍を変わり目の候補にして、台割と照らす。候補が出たら、**50ミリ秒刻みで帯域別の音量を出して、打撃の正確な時刻を決める**（拍の単位のままだと0.05〜0.1秒ずれ、「若干ずれてる」と言われた）。切り替えは打撃の1コマ前に置く。直前に**音が止まる隙間**があれば、そこで画面を吸い込むように溜め（寄る・レンズを狭める・周辺を暗く）、打撃で一気に引いて広い空間を見せる。打撃で「近く・低く・トンネルの中」へ入るのは開放感の逆。
- **間奏や後半の「開放感」は、物を減らすことではない**。地面と太陽と細い線だけの空っぽの画面が9秒続き、「しょぼい」と言われた（2026-10-07）。広い空間に、大きな主役の物体と画面を埋める量を置き、小節ごとに主役を替える。

- 1音ごとの文字の出は、文字起こしの syl（等分推定）を使わない。歌声の分離音源で立ち上がりを取り、語頭をそこに合わせ、語内は曲の8分格子で割り振る（例 `examples/yoru-code/scripts/fix_syl.py`）。コマ一覧で「く」と歌った瞬間に「く」が出るかを確かめる
- 音の変わり目は全体の音量でなく楽器ごと（drums/bass/other/vocals）に20ms刻みで見る。「チャーン」が上物だけで先に鳴り、ドラムが後から入ることがある（yoru 0:28 = 28.12 と 28.54）
- 音程が段々下がる所はカメラも段ごとに下げる。速度線の星はダサいので使わない。終盤の山場は、中央に左右対称で収まる紋章（完成形の絵）にする

## 手順

### 1. 新規プロジェクト（自動）
歌詞を `lyrics.txt` に書く（1行=1歌詞行、空白=言葉の区切り。Suno の mp3 なら `ffprobe -show_entries format_tags=lyrics` で公式歌詞が取れる）。
```bash
bash ~/.claude/skills/lyric-mv-3d/scripts/new_project.sh <作成先の絶対パス> <曲.mp3> <lyrics.txt> --vertical --bpm <だいたいのテンポ> --title "<曲名>"
```
エンジンの複製、縦長への切り替え、Demucs による4分離、声だけの文字起こし（mlx_whisper）、公式歌詞との文字単位の照合、`data/audio.json`・`data/lyrics.json`・`app/src/timeline.ts` の生成、git の初期コミットまでを行う。
最後に「歌詞一致 n/m 文字」と台割を表示する。一致率より**台割の時刻**を見る（同音の聞き違い「コード→行動」が多いと6割台でも時刻は正しい）。
間奏のあとの行が間奏の頭に寄っていたら、`work/whisper.json` の segments を見る。文字起こしは暴走止め（前の文脈を引き継がない）付きで、1文字も一致しない行は「どの行にも一致しなかった聞き取り区間」に自動で割り当てる（「ご視聴ありがとうございました」等の定番の聞き違いでも時刻は使える）。

### 2. 台割の確認
`app/src/timeline.ts` は「1歌詞行=1場面（id `m01`〜）＋4秒以上の間奏は `brkNN`」になっている。場面の境目を直すときはこのファイルを編集する。

### 3. 絵コンテと指示書
`references/scene_brief_template.md` を `<PROJECT>/SCENE_BRIEF.md` にコピーし、`{{...}}` を埋める。
Treatment は歌詞1行ずつに「何を3Dで見せるか・カメラ・主役の言葉」を書く。言葉を文字どおり絵にする（例: 「点と線」→点が打たれ線でつながる3Dの星座）。ここで質が決まるので上位モデルが書く。

### 4. 確認用サーバー
```bash
cd <PROJECT>/app && PDOOM_NO_HMR=1 nohup bunx vite --port <空きポート> --strictPort > ../out/vite.log 2>&1 &
```
5173 は使わない。ポートは `lsof -i :<port>` で空きを確かめる。

### 5. 場面づくり（並列）
場面を3〜4グループに分け、Agent（model: opus）を並列に起動する。各エージェントへは「SCENE_BRIEF.md を読んで従う・担当 id・担当ファイル以外を触らない・ファイルは Write/Edit のみ」を英語の電文体で渡す。
並列中は、各エージェントが `out/draft/<id>/` に出す静止画とコマ一覧が増えているかを定期的に確かめる。

並列中の注意: 確認用サーバーは新しく作った場面ファイルを拾うまで1〜2分かかる（「scene module not found」）。エージェントには待ってから撮り直すよう伝える。

### 6. 確認（上位が自分の目で）
```bash
cd <PROJECT>/app && bun scripts/render.ts sheet --url http://localhost:<port> --from 0 --to <曲の長さ> --n 16 --cols 4 --out ../out/check/sheet.png
```
Read で開き、`out/ref_sheet.png`（前作の見本コマ一覧。前作の完成mp4が `$LYRIC_MV_ENGINE/out/video/aitowatashi_mv_v3_youtube.mp4` にあるときだけ自動生成される。無ければ自作の見本と並べる）と並べて「同じ系統に見えるか」「平面になっていないか」「文字が切れていないか」を見る。

### 7. 書き出し
```bash
cd <PROJECT>/app && nohup bun scripts/render.ts video --url http://localhost:<port> --samples 12 --shutter 0.2 --fps 60 --out ../out/video/mv.mp4 > ../out/render.log 2>&1 &
```
前作は横長56秒で 59分37秒、縦長51秒（夜をほどくコード）で 38分09秒かかった（`--samples 12`）。物の多い場面（窓400枚の間奏など）は速さが半分以下に落ちるので、見張りの予想は余裕をもたせる。`--samples auto` は数時間かかるので使わない。待つ間は `out/render.log` の進み具合を見る。

### 8. 仕上げ
- 音量を -14 LUFS / -1 dBTP にそろえる（動画は無劣化でコピーし、音声だけ再エンコードする）。
  `ffmpeg -i in.mp4 -c:v copy -af loudnorm=I=-14:TP=-1:LRA=11 -c:a aac -b:a 192k out.mp4`
- 完成版を任意の書き出し先（例: `~/Downloads/`）にもコピーする。
- 依頼者の指摘で直した点は `<PROJECT>/implementation-notes.md` に記録し、繰り返し出る好みはこの SKILL.md の「依頼者の好み」に追記する。

## 一部だけ直すとき
直した場面の範囲だけ `render.ts video --from a --to b` で書き出し、全編に差し込む（`ffmpeg -ss/-t` で切り出して `-f concat -c copy` でつなぐ。音声は元の曲を全編に当て直す）。
