# 2026-10-03

## 場面の区切りを「拍に吸着」から「近い拍だけ吸着」に変更
- 仕様: 区切りは歌詞の行頭を拍に合わせる（timeline.ts 冒頭コメント）
- 判断: 行頭から0.1秒以内に拍があるときだけ拍に合わせ、それより離れていれば行頭そのもので切る
- 理由: 一番近い拍が1拍手前にあると、前の行の最後の音が切れていた
- 影響: app/src/timeline.ts の cut()。区切りは s02=5.895 … s10=42.133

## 本の場面（s06）の橙色の漏れを抑えた
- 仕様: 橙色は画面の1〜2割まで（元の映像は暖色の画素が約4%）
- 判断: 光る本から周りの棚へ漏れる光の届く範囲と強さを下げ、本のまわりの光の輪も小さくした
- 理由: 下書き全編で、暖色の画素が平均30%・最大48%（28.1秒）と、ほかの場面（平均2〜13%）から飛び抜けていた
- 影響: s06-glsl.ts の bl と halo の2行。完成版の実測で平均10.3%・最大28.7%（ほかの場面の最大は12〜29%）。元の版は old/s06-glsl.ts.before-spill-fix。見比べ用の画像は out/check/

## 本番の書き出しを「1コマ最大36枚の自動」から「1コマ12枚の固定」に変更
- 仕様: --samples auto --max-samples 36
- 判断: --samples 12 で書き出す
- 理由: 自動設定の計測で、温度の場面の1秒分に5分以上かかり、全編で数時間かかる見込みになった。12枚の固定で実測59分37秒
- 影響: 動きのぶれ表現とちらつき除去は12枚分になる。下書き（1枚）の虹色のちらつきは12枚で平均されて消える

- 理由: 書き出しのたびに 404 のエラーがログに出ていた
- 影響: app/index.html の2行

## 素晴らしい質問の場面（s02）を落ち着かせた（依頼者指摘「うざい」）
- 仕様: SCENE_BRIEF は「甘ったるく不気味に」。拍ごとに言葉が跳ね、紙吹雪の火花、メーター上昇
- 判断: 背景のスマイルの群れを消し、放射線は拍で回さず一定速度でゆっくり流し、大きなスマイルの拍ごとのうなずき・膨らみ・光り・縁の火花をなくした。言葉の頭での小さな会釈と、歌詞・メーターは残した
- 理由: 完成版を見た依頼者が「素晴らしい質問ですね のところがうざい」。5つの要素が同時に拍で動き、押しつけがましく見えていた
- 影響: s02.ts（crowdK=0、maskRot、rayRot、glow、punch、confetti）と s02-glsl.ts（crowd を描かない、放射線の太さが拍で変わらない）。元の版は old/s02*.before-calm。完成版には 5.8〜10.1 秒だけ書き出し直して差し込む

## 全場面で拍ごとの揺れを止めた（依頼者指摘「いちいち拍に合わせて揺れなくてもいい」）
- 仕様: SCENE_BRIEF「Something moves in every beat: use f.a.kick / f.beat / audio.hit for punches」
- 判断: エンジンの入口（engine/audio.ts）で kick の信号を0にし、全場面の拍ごとのカメラ前後動・ズーム・揺れ・光の脈打ちを一括で止めた。仕上げ（engine/post.ts）で画面の揺れを3割・言葉で入るズームを半分に弱めた。言葉の頭で入る動きは残した
- 理由: 依頼者が完成版を見て、拍ごとに揺れる動きを不要と判断した。揺れの処理が10場面に散らばっており、入口で止めるほうが漏れがない
- 影響: 拍の位相（f.beat / beatPhase）で動く要素（確率の場面の波紋、時計のコロンの点滅など）は残っている。元の版は old/audio.ts.before-nobeat と old/post.ts.before-nobeat。新しい完成版は out/video/aitowatashi_mv_v2.mp4

## 拍ごとの動きが残っていた2場面（s07・s04）を直した
- 判断: 会話の場面（s07）の前半は、拍ごとに急に振り向くカメラを、次の拍までなめらかに移る動きに変えた。後半の拍ごとの押し出しと顔の拍ごとの膨らみは止めた。歯車の場面（s04）の輪は、拍ごとに一段ずつ回るのをやめて一定の速さで回るようにした
- 理由: v2 を測ったところ、拍の直後の動きの量は拍と拍の中間の量の 4.2倍（s07）と 1.52倍（s04）で、拍に合わせた揺れが残っていた。kick を0にしても、拍の位置で動きを切り替える処理が場面の中に直接書かれていた
- 影響: s07.ts と s04-geo.ts。元の版は old/s07.ts.before-nobeat と old/s04-geo.ts.before-nobeat。全編は書き出し直さず、2場面の範囲（14.2〜20.35秒、29.6〜33.7秒）だけを書き出し直して v2 に差し込む（work/splice_parts.sh）。時計の場面（s09）の、拍ごとに針が刻む動きは時計らしさとして残した
- 結果: out/video/aitowatashi_mv_v3_youtube.mp4（-14.06 LUFS / -2.54 dBTP、3357コマ）。work/beat_motion.py で測った拍連動の比は s07 が 3.37→1.17、s04 が 1.32→1.22。ほかの場面は v2 と同じ値で、継ぎ目の前後に新しい動きの跳ねはない
